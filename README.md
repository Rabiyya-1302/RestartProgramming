# RestartProgramming

> Learning to think like an engineer, not just write code.

## About This Repository

At some point, I realized that I was writing code without truly understanding the principles behind it. I could build things, follow tutorials, and complete projects, but my foundation was not as strong as I wanted it to be.

This repository marks a deliberate restart of my programming journey.

Not because I am a beginner.

But because I want to rebuild my skills from first principles and develop the mindset of a software engineer.

The goal is not to complete challenges as quickly as possible. The goal is to deeply understand every concept, algorithm, design decision, and trade-off behind the code I write.
## Mission

To transform programming knowledge into engineering understanding through deliberate practice, experimentation, and project-based learning.

Every project in this repository is designed to answer questions such as:

* Why does this solution work?
* What are the alternatives?
* What are the trade-offs?
* How does it scale?
* How would this be implemented in a production environment?
