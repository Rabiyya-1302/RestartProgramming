# RestartProgramming

Learning programming again, this time with a focus on understanding rather than memorization.

## About

This repository documents my journey of rebuilding my programming fundamentals from the ground up. The goal is not to rush through tutorials or collect projects, but to develop strong problem-solving skills and learn how to think like a software engineer.

## What You'll Find Here

* Python practice projects
* Data structures and algorithms
* Problem-solving exercises
* Software engineering concepts
* Experiments and learning notes

## Goal

To build a solid foundation in programming and software engineering through consistent practice, curiosity, and hands-on projects.

Every project is an opportunity to learn, improve, and understand the reasoning behind the code.

## Philosophy

* Understand before optimizing
* Build before consuming
* Learn by doing
* Improve one project at a time

## Long-Term Vision

To become a skilled software engineer capable of designing, building, and maintaining reliable software systems.

> "The goal is not just to make the code work, but to understand why it works."
